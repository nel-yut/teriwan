# 幻獣綺譚 — 星渡りの門 —

モンスター(幻獣)を仲間にして育て、配合で強くし、星冠杯の優勝を目指すブラウザRPG。
スマホ縦持ち優先、PC でも遊べます。初回読み込み後はオフラインで動作します(PWA)。

- キャラクター・モンスター・文章・見た目はすべてオリジナル。グラフィックはコードで生成するドット絵(幻獣100種・マップタイル・探索キャラ)
- 設計書: [`docs/DESIGN.md`](docs/DESIGN.md)(末尾に実装との差分メモあり)

## 遊び方

1. 「はじめから」で名前を入れ、最初の相棒(♂♀2体)を選ぶ
2. 「門の間」から門へ。歩くと戦闘になる。戦闘中に **肉** を投げると、勝利後に仲間になりやすい
3. 「星冠競技場」で大会に勝つと新しい門と配合堂が解放される
4. 配合堂で ♂と♀(Lv10以上)を掛け合わせて卵を作り、戦闘を重ねて孵化させる
5. 8つの門を攻略して星冠杯に優勝するとエンディング。以降は収集・育成を自由に続けられる

操作: 移動は矢印キー / WASD / 画面の十字ボタン。会話は Enter / タップで送る。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト + 全配合組合せ検証 + AI 自動プレイ
npm run build      # dist/ に静的ファイルを出力(Service Worker のプリキャッシュ一覧も生成)
npm run preview    # ビルド結果をローカルで確認
```

### GitHub Pages で公開する

1. `main` ブランチに変更を取り込む(`.github/workflows/pages.yml` が `main` への push で自動デプロイします)
2. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** にする
3. Actions タブでデプロイ完了を待つと、`https://<ユーザー名>.github.io/teriwan/` で遊べます(スマホ可・HTTPS なのでオフライン対応も有効)

`dist/` を任意の静的ホスティング(GitHub Pages など。相対パスで動作)に置けば公開できます。HTTPS(または localhost)でのみ Service Worker が有効になります。

### ドット絵

- 幻獣: `src/ui/pixel.ts` が 24×24 のドット絵を種族ごとに生成(体型テンプレートに、部位の組み合わせ・体型の比率・模様・目と口・小物・色を種族ごとに変え、ランクでサイズやきらめきが変わる)
- マップ: `src/ui/tiles.ts` が 16×16 のタイルを門ごとの配色と模様で生成
- **自作・AI生成のドット絵に差し替える**: `public/assets/monsters/M001.png` のように種族 ID 名で PNG を置き、`public/assets/manifest.json` の `monsters` に ID を並べると、その種族だけ画像が優先されます(正方形、透過PNG、24〜64px 程度を推奨。拡大はニアレストネイバーで表示)

### 構成

```
src/domain/          DOM 非依存の純粋ロジック(戦闘・配合・ダンジョン生成・乱数)
src/data/            マスターデータ(100種・30技・アイテム・門・大会・ストーリー) と起動時検証
src/application/     ゲーム状態(Game クラス): 進行・保存・ショップ・配合の確定
src/infrastructure/  セーブ(IndexedDB、3スロット、ハッシュ検証、1世代バックアップ)
src/ui/              DOM + Canvas の画面群
tests/               単体テスト、100×100配合の網羅、AI全自動クリアのシミュレーション
```

### テストで保証していること

- 100種×100種すべての配合に有効な結果があり、100種すべてが入手可能
- 全8門・全階層が100シード以上で入口から出口へ到達可能
- 同じ seed と入力なら戦闘・生成結果が再現される
- 配合の保存に失敗しても親が消えない(セーブはトランザクション的に更新)
- AI の自動プレイだけでエンディングまで到達できる
